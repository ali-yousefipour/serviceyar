# اتصال نشان

نشان انتخاب پیش‌فرض نقشه و مسیریابی است. تنظیمات شرکت شامل `map_provider`، `neshan_service_key` و `neshan_web_key` است. کلید سرویس با `is_secret=1` ذخیره و از پاسخ تنظیمات حذف می‌شود؛ ورودی خالی مقدار قبلی را حفظ می‌کند. کلید وب در مرورگر قابل مشاهده است و باید در پنل نشان به دامنه مجاز محدود شود.

نمایش نقشه به کلید جداگانه Web SDK نیاز دارد. تا تنظیم آن، OSM با پیام روشن نمایش داده می‌شود. SDK رسمی Leaflet نسخه 1.0.8 استفاده شده است. مسیریابی سمت سرور از GET /v4/direction با هدر Api-Key، TLS، محدودیت حجم پاسخ و timeout استفاده می‌کند. فراخوانی واقعی سرویس و بررسی بصری این تغییرات هنوز انجام نشده است.

کلیدهای ارسالی در فایل‌های ignored محلی `storage/cache/neshan-service-key.txt` و `storage/cache/neshan-web-key.txt` ذخیره شده‌اند. برای production از `NESHAN_SERVICE_KEY` و `NESHAN_WEB_KEY` یا تنظیمات شرکت استفاده شود. مقدار ثبت‌شده در تنظیمات شرکت اولویت دارد؛ مقدار خالی صریح Web، نمایش SDK را غیرفعال می‌کند. این تغییرات روی هاست منتشر نشده‌اند.

بررسی انتخاب کلید Web شامل اولویت تنظیمات شرکت، متغیر محیطی، فایل محلی، غیرفعال‌سازی صریح و رد کلید نامعتبر انجام شد. بررسی مرورگر به دلیل در دسترس نبودن سرویس محلی پورت 8088 به نمایش نقشه نرسید.
