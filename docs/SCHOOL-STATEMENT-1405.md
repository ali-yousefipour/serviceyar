# منطق صورت‌وضعیت مدارس ۱۴۰۵/۱۴۰۶

منبع: فایل مدارس 1405.xlsm کاربر، شیت اطلاعات پایه1، تعرفه‌های 1 تا 3 و بهای خدمات اولیا5. این سند تعرفه عمومی یا قانونی خارج از همین فایل را تأیید نمی‌کند.

- تعرفه: جستجوی دقیق مسافت در جدول کلاس خودرو؛ درون‌یابی انجام نمی‌شود.
- ضرایب ناحیه: ۱ و تبادکان = ۱؛ ۲، ۵، ۷ = ۱٫۱؛ ۳، ۴، ۶ = ۱٫۲۵.
- مبنا = تعرفه × ضریب ناحیه؛ کارکرد = مبنا × روز / ۳۰.
- مدیریت ۳٪ کارکرد؛ هماهنگی ۱٪؛ سهم شرکت ۷٪.
- شهرداری ۲٫۷۵٪ کارکرد؛ ارزش افزوده ۱۰٪ سهم شهرداری؛ راهور ۰٫۲۵٪ کارکرد.
- صلاحیت به ازای ردیف دارای کارکرد مثبت: ۱۱۵۷۴۱ ریال.
- جمع سهم‌ها در خود فایل = کارکرد + مدیریت + هماهنگی + شرکت + صلاحیت. شهرداری/ارزش افزوده/راهور در این جمع وارد نشده‌اند.
- بیمه = ۷٫۸٪ جمع سهم‌ها؛ مبلغ ولی = جمع سهم‌ها + بیمه.
- صورت وضعیت بدون صلاحیت و بیمه = کارکرد + مدیریت + هماهنگی + شرکت.

کلاس 1 شامل ۴۲ مسافت، کلاس 2 شامل ۴۱ و کلاس 3 شامل ۵۴ مسافت استخراج شد. موتور PHP از کسرهای صحیح استفاده و نمایش را تا ۶ رقم اعشار قطع می‌کند؛ گردکردن ریالی برای ثبت مالی هنوز سیاست تأییدشده‌ای ندارد.

API: POST /api/v1/operations/school-statement/preview با finance.view، محدوده شرکت و CSRF. ورودی vehicleClass (1/2/3)، distanceKm، region و days (عدد صحیح صفر تا ۳۰). هیچ داده‌ای ذخیره یا به حسابداری ارسال نمی‌شود.

اعتبارسنجی: ۱۲ مبلغ ردیف نمونه، کارکرد صفر و چهار ورودی نامعتبر موفق. از ۶۳۰ ردیف منبع، ۵۳۷ ردیف دارای کلاس قابل استخراج بود: ۴۱۶ ردیف با خروجی ذخیره‌شده منطبق؛ ۱۲۰ ردیف خروجی صفر ذخیره‌شده ولی ورودی قابل تعرفه دارند؛ یک مسافت متنی نامعتبر است. ۹۳ ردیف فاقد کلاس قابل استخراج در تطبیق محاسبات وارد نشدند. علت صفرهای فایل هنوز تعیین نشده است؛ احتمال خطای lookup، نوع داده یا cache مطرح است و هیچ‌کدام اثبات نشده‌اند.

رابط، تجمیع نهایی رانندگان، آرشیو ماهانه، مفاصا و سند سازمان هنوز از این موتور تولید نمی‌شوند. دروازه پنج‌اسکیلی کاربر برای تغییر UI و نصب مستقل Extract همچنان برقرار است. روی سایت زنده منتشر نشده است.
