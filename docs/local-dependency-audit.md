# ممیزی وابستگی‌های سمت مرورگر — سرویس‌یار

## هدف

کتابخانه‌های قابل میزبانی محلی باید از `service-yar.ir` سرو شوند تا برای دریافت کد و استایل به DNS/CDN خارجی در مرورگر نیاز نباشد. APIهای زنده و داده‌های نقشه، پیامک و مسیریابی کتابخانه نیستند و بدون توافق ارائه‌دهنده نباید Mirror شوند.

## موجودی تأییدشده از سورس

| وابستگی | وضعیت | مسیر |
| --- | --- | --- |
| Leaflet JS/CSS | از قبل محلی | `/assets/leaflet.js` و `/assets/leaflet.css` |
| PDF html2pdf | از قبل محلی؛ بارگذاری هنگام نیاز | `/assets/html2pdf.bundle.min.js` |
| Vazirmatn | از قبل محلی | `/assets/Vazirmatn-Regular.woff2` |
| خروجی XLSX با SimpleXLSXGen | PHP داخل بک‌اند | `backend/src/Vendor/SimpleXLSXGen.php` |
| SDK مرورگر نشان | انتقال به هاست در Deploy | `/assets/vendor/neshan/v1.0.8/index.js` و `index.css` |

## انتشار SDK نشان

- دو مسیر استفاده‌کننده: `frontend/assets/public-site.js` و `frontend/assets/operations.js`.
- فایل‌های SDK نسخه مشخص `v1.0.8` در **زمان آماده‌سازی انتشار** از منبع رسمی دریافت و در payload میزبانی محلی قرار می‌گیرند: `tools/vendor_neshan_sdk.py`.
- به‌دلیل باینری بودن وابستگی‌ها، فایل‌های SDK در هر انتشار در payload قرار می‌گیرند و **در مخزن Git ذخیره نمی‌شوند**؛ صرفِ تغییر URL در کد به‌معنی موجود بودن فایل روی هاست نیست.
- اگر پاسخ SDK نامعتبر باشد یا حتی یکی از فایل‌های وابسته قابل دریافت نباشد، مرحله انتشار متوقف می‌شود. مسیر مرورگر هیچ CDN جایگزین خارجی ندارد.
- پس از آپلود، `tools/deploy_serviceyar.py` فایل‌های JS/CSS را از دامنه عملیاتی دریافت و SHA-256 آن‌ها را با فایل مرحله انتشار مقایسه می‌کند.
- `SHA256SUMS` و `SOURCE.txt` داخل پوشه نسخه قرار می‌گیرند. برای استفاده مجدد یا توزیع جداگانه، شرایط مجوز ارائه‌دهنده SDK بررسی شود.

## وابستگی‌هایی که عمداً محلی نشده‌اند

- درخواست‌های Tile نقشه نشان/OSM، جستجوی مکان، مسیریابی و Reverse Geocoding داده‌های زنده و تحت قرارداد/سهمیه ارائه‌دهنده‌اند؛ خودسرانه Mirror کردن آن‌ها هم از نظر حجم غیرعملی و هم از نظر مجوزها پرریسک است.
- پیامک، ربات بله و APIهای یکپارچه‌سازی بک‌اند، سرویس هستند نه کتابخانه CDN مرورگر.
- برای قابلیت Offline نقشه باید جداگانه مجوز داده، محدوده جغرافیایی، حجم ذخیره و سیاست Cache تأیید شود.

## آزمون

```bash
node tests/local-map-assets.cjs
python3 tests/vendor-neshan-sdk.py
python3 -m py_compile tools/vendor_neshan_sdk.py
```

بهبود واقعی زمان بارگذاری باید در مرورگر عملیاتی با Network، Cache و Web Vitals اندازه‌گیری شود؛ حذف دانلود از CDN خارجی الزاماً به معنای کاهش قطعی زمان در تمام شبکه‌ها نیست.
